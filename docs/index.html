Core Engineering

Built specifically for 2026 agent runtimes

Zero Legacy Wrappers

No spotipy, no Node.js subprocesses. Built on Python 3.10+ using httpx and official mcp[cli]>=2,<3.

Remix-Aware Matcher

Normalizes artist credits (Fred again..), folds accents (Böhmer → Bohmer), and rewards requested remixes while filtering unwanted edits.

Proactive PKCE Auth

Secure local PKCE authorization with automatic browser login. Atomic file updates to tokens.json (mode 0o600) with asyncio.Lock rotation.

Quickstart

Connecting to Your MCP Client

Step 1 Register Spotify App

Create an app in the Spotify Developer Dashboard, configure your redirect URI as specified in .env.example, and note your Client ID.

SPOTIFY_CLIENT_ID=your_client_id
Step 2 Clone & Authenticate
git clone https://github.com/verisonSachin/spotifyMCP.git
cd spotifyMCP
cp .env.example .env && nano .env
uv sync
uv run --env-file .env spotify-mcp-auth
Step 3 Register in AI Agent Config

Add to mcp_config.json or opencode.json:

{
  "mcpServers": {
    "spotify": {
      "command": "uv",
      "args": ["--directory", "/path/to/spotifyMCP", "run", "spotify-mcp"],
      "env": { "SPOTIFY_CLIENT_ID": "your_client_id" }
    }
  }
}
